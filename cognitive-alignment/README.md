# 认知对齐系统

> 人类心智模型与 AI 智能体的标准化对齐验证

## 核心理念

在 Code Agent 时代，代码由 AI 生成，认知由人类定义。

**认知对齐 = 人类心智模型（agents.md）+ 执行状态反馈（goals.json）**

```
┌─────────────────────────────────────────────────────────────┐
│                    认知对齐系统                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │

│  │  agents.md   │  ──────▶│  goals.json  │                 │
│  │  认知投射层  │         │  执行反馈层  │                 │
│  │  (人类→AI)   │         │  (AI→人类)   │                 │
```

## 五层认知架构

所有 agents.md 必须按从顶层价值到底层数据的认知顺序编写：

| 层级 | 核心问题 | 必填内容 |
|------|---------|---------|
| **价值层** | Why - 为什么存在 | 核心定位、边界取舍、优先级规则 |
| **规则层** | What - 做什么/不做什么 | 硬约束、运行约束、异常处理 |
| **结构层** | How - 如何运作 | 依赖关系、执行链路、协作关系 |
| **概念层** | Terms - 术语统一 | 项目专属名词、缩写对照 |
| **感知层** | Data - 输入输出 | 接收输入、必须输出、样板代码 |

## 快速开始

### 1. 创建 agents.md

复制模板并填写：

```bash
cp cognitive-contract/agents-template.md /path/to/project/AGENTS.md
```

### 2. 增强 goals.json

在现有 goals.json 中添加认知契约元数据：

```json
{
  "cognitive_contract": {
```

## 元认知三段式工作流

### 事前规划（Planning）
- 明确本次修改的真实意图
- 枚举当前缺失的认知缺口
- 预判 AI 可能的幻觉点

### 事中监控（Monitoring）
- 禁止系统1直觉写作
- 检查隐性假设
- MECE 校验：规则是否重叠、是否遗漏

### 事后复盘（Review）
- 本次更新杜绝了哪些错误
- 是否仍有模糊语句
- 迭代沉淀：临时规则固化为通用模式

## 图式迭代机制

### 同化（Assimilation）
- 新增能力、补充规则、追加案例
- 不改动原有五层结构骨架
- 适配 90% 的日常更新场景

### 顺应（Accommodation）
- 架构升级、理念变更、职责重构
- 主动重构整体结构
- 低频率、高价值迭代

## 知识三层网络

### 原则层（不变）
OpenCode 底层理念：
- 声明式优先
- 配置即真相
- 轻量稳定
- 多语言异构服务统一管控

### 模式层（可复用）
- 进程管理模式
- 日志规范模式
- 目录规范模式
- Prompt 约束模式

### 案例层（场景落地）
- Caddy 配置案例
- Node 服务案例
- Python 服务案例
- supervisord 配置案例

## 认知级验收标准

一篇合格的 agents.md 必须满足：

- [ ] **无隐性假设**：所有默认规则全部显性写出
- [ ] **五层完整**：价值→规则→结构→概念→数据，无缺失层级
- [ ] **心智对齐**：无需人类补充解释，AI 可独立完成合规开发
- [ ] **结构稳定**：符合图式迭代规则，可长期同化迭代
- [ ] **知识可沉淀**：每条内容归属原则/模式/案例三层体系
- [ ] **规避认知偏见**：无直觉化模糊描述，全部可校验、可落地

## 90 天认知落地计划

### 1-30 天：元认知基础
- 掌握快/慢思考、元认知自检
- 每一次改 agents.md 先做 1 分钟元认知复盘

### 31-60 天：五层认知拆解
- 熟练五层认知拆解
- 所有新增章节严格分层编写

### 61-90 天：知识三层架构
- 搭建完整知识三层架构
- 完成所有 agents.md 结构化重构
